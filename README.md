# TTN QA AI Practical Assessment

This repository contains the QA AI Capability Exercise submission for Practice Software Testing Toolshop.

## Quick Start

```bash
cd qa-ai-practical-assessment/PrismStructure
npm install
npx playwright install chromium
npm test
```

See [qa-ai-practical-assessment/readme.md](qa-ai-practical-assessment/readme.md) for full documentation.

## Contents

- **FunctionalTestCase.csv** – Manual test suite (8 cases)
- **PrismStructure/** – Playwright UI + API automation with execution reports
- **project-info.md** – AI workflow documentation
- **ai-prompts/** – Prompt history by phase
